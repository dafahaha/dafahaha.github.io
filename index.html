Selected Projects

TransitTruth

Open-source auditing tool · behavioral fingerprinting of AI API relays · 2026

An open-source system that checks whether an AI API relay actually serves the model it advertises. Instead of trusting the relay's label, it probes the model's statistical behavior — random-number, token, and latency distributions — and compares them against a baseline using chi-square / KS tests with Bayesian updating. A zero-install, fully client-side web demo lets anyone run the audit in ~30s. The accompanying 20-page technical report validates same-family discrimination (gpt-4o vs gpt-4o-mini, TVD up to 0.90, 91.3% posterior identification), focusing on fine-grained distinctions that single-token fingerprinting does not reach.

rl-deploy-bench

Cross-platform RL deployment & benchmarking toolkit · v1.1.0

A config-driven CLI that exports Stable-Baselines3 policies to ONNX/TorchScript, builds TensorRT engines with FP16/INT8 quantization, and benchmarks latency, throughput, and accuracy across x86 GPU, NVIDIA Jetson, and CPU, with auto-generated HTML reports — a reproducible harness for the accuracy–latency tradeoff of quantized RL policies.
