TransitTruth

Open-source auditing tool · behavioral fingerprinting of AI API relays · 2026

An open-source system that checks whether an AI API relay actually serves the model it advertises. Instead of trusting the relay's label, it probes the model's statistical behavior — random-number, token, and latency distributions — and compares them against a baseline using chi-square / KS tests with Bayesian updating. A zero-install, fully client-side web demo lets anyone run the audit in ~30s. The accompanying extended technical report validates same-family discrimination (gpt-4o vs gpt-4o-mini, TVD up to 0.90, 91.3% in-distribution resubstitution posterior — self-consistency on the baseline's own reference, not held-out accuracy), focusing on fine-grained distinctions that single-token fingerprinting does not reach.

wm-audit

Preregistered world-model audit suite · perceptual fidelity vs control utility · 2026

A preregistered, single-machine CPU audit suite that disentangles a world model’s perceptual fidelity (next-frame MSE / SSIM / NLL, plus fixed-filter stand-ins for LPIPS / rollout FVD — deterministic random-conv filter banks, not learned VGG/AlexNet backbones) from its control utility (whether a planner can actually solve the task using it). A reduced pilot on one env (pixel_nav, 3 seeds × 3 capacities, 12k steps) found: pixel fidelity weakly predicts closed-loop return (H1 supported, |ρ|=0.32<0.4); control-relevant diagnostics did not (H2 not supported, ρ=0.26<0.6); INT8 compression did not degrade calibration faster than raw pixel fidelity (H3 not supported, n_pairs=9). This is a CPU reduced pilot, not the locked 200k-step × 5-seed × 2-env main run.

embodied-offpolicy-study

Pre-registered three-arm controlled study · Hopper-v4 · CPU, 120k steps · 2026

A Soft Actor-Critic implementation written from scratch in PyTorch (no Stable-Baselines3), run as a pre-registered three-arm controlled study on Hopper-v4 (CPU, 120k env steps, 3 seeds/arm): Baseline (reward scale 1.0) vs RewardScaled (0.1) vs FixedAlpha (0.1, automatic temperature off, α fixed at 0.2). Mean return ± SD (final window 105k–120k, n=3/arm): Baseline 1085±698, RewardScaled 1118±623, FixedAlpha 1404±632. Welch p: Baseline–FixedAlpha 0.59, Baseline–RewardScaled 0.95, FixedAlpha–RewardScaled 0.61; ANOVA F=0.22, p=0.81 — no statistically distinguishable effect detected (n=3; t-intervals overlap heavily). The study's value: at 60k the reward-scaled arm looked ~3× better, but extending to the pre-registered 120k budget and adding the fixed-temperature control arm overturned that apparent gain as early seed noise — an honest pre-registered null. Raw CSVs are committed and curves reproduced by script.

rl-deploy-bench

Cross-platform RL deployment & benchmarking toolkit · v1.1.0

A config-driven CLI that exports Stable-Baselines3 policies to ONNX/TorchScript and builds TensorRT engines with FP16/INT8 quantization; benchmarks latency, throughput, and accuracy on x86 GPU and CPU, with auto-generated HTML reports — a reproducible harness for the accuracy–latency tradeoff of quantized RL policies. Jetson/edge is a target deployment path, not yet measured on device.
